# Design Apple

Skill para Codex que transforma principios publicos das Apple Human Interface Guidelines em criterios praticos para criar sites e interfaces modernas, acessiveis e autorais.

> Projeto independente, sem afiliacao, aprovacao ou patrocinio da Apple Inc. O nome Apple e marcas relacionadas pertencem aos seus respectivos titulares. A skill nao distribui fontes, icones, templates ou outros materiais proprietarios da Apple.

## O que a skill faz

- Pergunta automaticamente se voce quer usar a Design Apple antes de criar um novo site.
- Estrutura interfaces a partir de proposito, contexto e tarefa principal.
- Organiza navegacao, conteudo e hierarquia antes da decoracao.
- Adapta layouts para telefone, tablet e desktop.
- Inclui acessibilidade, estados, feedback e movimento reduzido.
- Exige identidade propria e impede copias de produtos Apple.

## Instalacao

Copie esta pasta para:

```text
~/.codex/skills/design-apple
```

Reinicie ou atualize o Codex para a skill aparecer na lista.

## Uso

```text
Use $design-apple para criar uma landing page moderna e autoral para minha empresa.
```

A skill tambem pode ser selecionada automaticamente em pedidos de sites e interfaces com acabamento premium ou inspiracao metodologica nas Human Interface Guidelines.
